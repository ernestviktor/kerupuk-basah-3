Panduan Aktivasi Google Calendar & OAuth Admin

Langkah konfigurasi satu kali untuk membaca jadwal publik dan mengaktifkan Create/Edit/Delete langsung dari panel admin.

1. Buat Kalender Publik Kampus

Buka Google Calendar, buat kalender khusus (misalnya Event Kampus), lalu buka Settings & sharing dan centang Make available to public (pilih See all event details).

2. Salin Calendar ID & API Key

Salin Calendar ID dari Google Calendar dan buat API Key (batasi ke Google Calendar API) di Google Cloud Console, lalu tempel ke calendarId dan apiKey di js/config.js.

3. Buat OAuth 2.0 Web Client ID

Di Google Cloud Console, buka APIs & Services → OAuth consent screen (tambahkan email panitia di Test users), lalu buat Credentials → OAuth client ID (Web application) dan daftarkan origin Live Server / GitHub Pages Anda.

4. Isi oauthClientId di js/config.js

Tempel Client ID berakhiran .apps.googleusercontent.com ke properti oauthClientId di js/config.js. Jalankan situs via Live Server atau GitHub Pages agar tombol Masuk dengan Google (Admin) aktif.
