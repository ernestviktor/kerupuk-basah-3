Workshop HTML & CSS Tanpa Framework HTML & CSS Workshop Without Frameworks

Pelatihan praktik membangun antarmuka web responsif, aksesibel, dan ringan hanya dengan HTML5 dan CSS3. Hands-on session on building responsive, accessible web interfaces using pure HTML5 and CSS3.

Deskripsi & Rundown Acara Description & Schedule

Peserta mempraktikkan CSS Grid, selector :has(), menu hamburger tanpa JavaScript, serta pengujian kontras warna dan ukuran layar ponsel. Participants practice CSS Grid, :has() selectors, JS-free mobile drawers, and responsive contrast checks.

13.00 - 13.45 WIB Struktur semantik HTML5 dan variabel CSS Semantic HTML5 structure and CSS custom properties
13.45 - 15.00 WIB Tata letak Grid, Flexbox, dan filter CSS :has() Grid, Flexbox layouts, and CSS :has() filtering
15.00 - 16.00 WIB Uji responsif 360px - 1440px dan publikasi GitHub Pages Responsive testing (360px - 1440px) and GitHub Pages deploy
